# Third-party components

MediaCatch is an independent Streamlit application that uses third-party open-source projects as dependencies.

- **yt-dlp** — media extraction/downloading engine. Project: https://github.com/yt-dlp/yt-dlp
- **Streamlit** — web application framework. Project: https://github.com/streamlit/streamlit
- **Playwright for Python** — browser automation used by authenticated browser mode. Project: https://github.com/microsoft/playwright-python
- **FFmpeg** — optional external dependency for media merging/conversion. Project: https://ffmpeg.org/
- **Deno** — optional/recommended JavaScript runtime for current YouTube challenge handling in yt-dlp. Project: https://deno.com/

Each third-party component is distributed under its own license and terms. MediaCatch does not bundle or relicense those projects merely by listing them as dependencies or invoking separately installed executables.
