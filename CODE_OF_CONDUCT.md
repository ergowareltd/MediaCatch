# Code of Conduct

## Our commitment

We are committed to making participation in the MediaCatch project a respectful, constructive and professional experience for everyone.

Contributors, users and maintainers are expected to communicate clearly, act in good faith and focus on improving the project.

## Expected behavior

Examples of positive behavior include:

- Being respectful and constructive
- Providing useful technical feedback
- Accepting reasonable criticism
- Keeping discussions focused on the project
- Respecting different levels of experience
- Helping other contributors understand the codebase
- Reporting bugs and security issues responsibly

## Unacceptable behavior

The following behavior is not acceptable:

- Harassment, insults or personal attacks
- Discriminatory or abusive language
- Threats or intimidation
- Deliberate disruption of project discussions
- Publishing private information without permission
- Sharing passwords, authentication tokens, cookies or other sensitive credentials
- Encouraging unauthorized access, DRM circumvention or misuse of MediaCatch
- Repeatedly ignoring maintainer guidance

## Project scope

MediaCatch is intended for legitimate media downloading and authenticated browser capture where the user has appropriate access and permissions.

Contributions must not add functionality specifically designed to:

- bypass DRM;
- defeat access controls without authorization;
- steal or expose authentication data;
- collect credentials;
- hide malicious or unauthorized behavior.

## Enforcement

Project maintainers may edit, reject or remove contributions, comments, issues or pull requests that violate this Code of Conduct.

Serious or repeated violations may result in temporary or permanent restriction from participating in the project.

## Reporting

If you need to report inappropriate conduct, contact the repository maintainer privately rather than posting sensitive details publicly.

For security vulnerabilities, refer to `SECURITY.md`.

## Scope

This Code of Conduct applies to:

- Issues
- Pull requests
- Discussions
- Code reviews
- Repository-related communication
- Other spaces where someone is representing the MediaCatch project
